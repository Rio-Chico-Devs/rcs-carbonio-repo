# ISTRUZIONI PER SCARICARE I FONT LOCALMENTE

## IMPORTANTE: Evitare Google Fonts per GDPR

### PASSO 1: Scarica i font
Vai su: https://google-webfonts-helper.herokuapp.com/fonts

**Per INTER:**
1. Cerca "Inter"
2. Seleziona charsets: latin
3. Seleziona styles: regular, 500, 600, 700
4. Clicca "Download files"
5. Estrai i file .woff2 e .woff

**Per TEKO:**
1. Cerca "Teko"
2. Seleziona charsets: latin
3. Seleziona styles: regular, 500, 600, 700
4. Clicca "Download files"
5. Estrai i file .woff2 e .woff

### PASSO 2: Rinomina i file
I file scaricati devono essere rinominati esattamente così:

**Inter:**
- inter-v13-latin-regular.woff2
- inter-v13-latin-regular.woff
- inter-v13-latin-500.woff2
- inter-v13-latin-500.woff
- inter-v13-latin-600.woff2
- inter-v13-latin-600.woff
- inter-v13-latin-700.woff2
- inter-v13-latin-700.woff

**Teko:**
- teko-v15-latin-regular.woff2
- teko-v15-latin-regular.woff
- teko-v15-latin-500.woff2
- teko-v15-latin-500.woff
- teko-v15-latin-600.woff2
- teko-v15-latin-600.woff
- teko-v15-latin-700.woff2
- teko-v15-latin-700.woff

### PASSO 3: Carica i file
Metti TUTTI i file .woff2 e .woff in questa cartella:
`/wp-content/themes/rcs-carbonpro-2026/assets/fonts/`

### PASSO 4: Verifica
Il file fonts.css è già pronto e caricherà automaticamente i font locali.
